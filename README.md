# Jev × Jstris

A local experiment: Jev chooses a reachable Tetris placement, and a browser controller executes it in Jstris using keyboard input.

Work in progress. The design and current Jstris state-reading evidence are in [docs/design.md](docs/design.md) and [docs/jstris-live-state-verification.md](docs/jstris-live-state-verification.md).

The TypeSafe API key will be configured locally after the key-free implementation is verified. No key is included in this repository.
